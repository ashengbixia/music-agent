# 约在下一个夏天

项目：毕业站台词稿

项目编号：song_001

## 文件说明

- lyrics.md：已审核歌词的 Markdown 副本。
- composition.json：已审核的作曲方案。
- audio.wav：已审核的 mock 测试音频。
- cover.png：需求单指定的占位封面。
- approvals.json：歌词及音频审核记录。
- manifest.json：物料清单、版本与文件校验值。

## 制作说明

本项目歌词与作曲方案由 AI 辅助生成，原创要求遵循歌曲需求单所列约束。音频为本地程序合成的 mock 测试音，未使用外部音频采样。本声明记录制作方式，不代表已完成原创性鉴定。

mock 音频不包含真实演唱，也不实际呈现作曲方案的编曲效果。

本物料包交给下游发行 Agent，本程序未执行平台发布。
