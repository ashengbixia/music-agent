# 约在下一个夏天

## 主歌1

情绪：温暖回忆，轻微不舍

铃声停在 最后一个夏天  
课桌刻痕 被阳光照浅  
走廊尽头 谁抱着旧照片  
把没说完的话 笑成一句随缘  

## 预副歌1

情绪：克制告别，鼓起勇气

我们拖着行李 走过熟悉校门  
像第一次报到 却少了兴奋  
站台广播 催着不同方向  
把名字喊一遍 就当勇敢  

## 副歌1·记忆点：约在下一个夏天

情绪：明亮坚定，合唱感

挥挥手吧 别把不舍说穿  
各自远行 约在下一个夏天  
风把校服吹成远行的帆  
我们不说散场 只说珍重一点  

## 主歌2

情绪：轻快怀念，带一点笑意

操场的线 还画着昨天  
篮球弹起 没接住的时间  
吉他弦上 跑调的那一段  
被谁录进手机 留作以后调侃  

## 预副歌2

情绪：温柔牵挂，悄悄不舍

列车穿过 城市不同的灯  
我们会遇见 新的名字和新的人  
可某个夜晚 耳机突然循环  
那年合唱 还站在风里等  

## 副歌2·记忆点：约在下一个夏天

情绪：坚定热烈，适合全场合唱

挥挥手吧 别把不舍说穿  
各自远行 约在下一个夏天  
把没唱完的歌 留给车站  
等重逢那天 再从副歌开始喊  

## 桥段

情绪：真挚释然，温暖有力

也许路会远 也许梦会偏  
也许忙碌把问候 拖成未接来电  
但请记得 我们约好的地点  
不是某座城 是彼此心里面  

## 尾声·记忆点复唱

情绪：温暖余韵，约定再会

挥挥手吧 别把不舍说穿  
各自远行 约在下一个夏天  
若你抬头 看见同样的月  
就当我们 还在同一片夜  
啦啦啦 约在夏天再见
